# Supermarket Basket & Checkout Queue System 🛒

This is a Python console-based Supermarket simulation using:
- **Stack** (Basket → Last item removed first)
- **Queue** (CheckoutQueue → First customer served first)

## Features
✅ Add Customer  
✅ Add Item to Basket  
✅ Remove Item from Basket  
✅ View Basket Items  
✅ View Checkout Queue  
✅ Checkout Customer  

## How to Run
```bash
python main.py
